# Goals & Expectations

## Project Vision
To create the ultimate, all-in-one USB-to-Serial bridge and analysis tool for embedded developers, powered by the ESP32-C6.

## Core Goals
1.  **Reliability:** Provide a stable UART bridge that doesn't drop bytes.
2.  **Versatility:** Support multiple modes (Bridge, Monitor, Bluetooth).
3.  **Usability:** Intuitive on-device UI via TFT display.
4.  **Portability:** Compact, battery-powered (optional), and easy to carry.

## Success Criteria
- [x] Successful USB-CDC to UART bridging.
- [x] Bluetooth LE configuration interface.
- [x] Real-time baud rate detection.
- [ ] Full SD card logging support (In Progress).
- [ ] Comprehensive documentation (This website).
