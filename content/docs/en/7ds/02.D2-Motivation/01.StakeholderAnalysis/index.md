# Stakeholder Analysis

## The Team

The SerialyTTY project is driven by a dedicated team of three engineers, each focusing on specific dimensions of the product.

### 👨‍💻 Denis Ivan
**Role:** Lead Developer & Hardware Engineer
- **Responsibilities:**
  - Core hardware design and implementation.
  - Firmware development (The "Hard Stuff").
  - Low-level driver implementation (UART, USB, Bluetooth).
  - System optimization and performance tuning.

### 🏗️ Danylo
**Role:** System Architect
- **Responsibilities:**
  - High-level system architecture design.
  - Component interaction planning.
  - Defining interfaces between modules (Display, Menu, Comm Tester).
  - Ensuring scalability and modularity of the codebase.

### 📝 Ondrej
**Role:** Project Manager & Documentation Lead
- **Responsibilities:**
  - Project tracking and timeline management.
  - Documentation maintenance (7 Dimensions, API docs).
  - Quality assurance and progress reporting.
  - User guide creation and maintenance.

## Other Stakeholders

### End Users
- Embedded systems engineers.
- Hobbyists working with UART/Serial devices.
- Developers needing a reliable USB-to-Serial bridge with advanced features.

### Open Source Community
- Contributors and users providing feedback via GitHub.
