# Welcome to SerialyTTY

SerialyTTY is a bridge between USB and UART/Serial devices, powered by ESP32-C6.

## Key Features
- **USB to UART Bridge**: Seamless communication.
- **Bluetooth LE**: Wireless configuration and control.
- **Display Support**: Visual feedback on TFT screens.
- **SD Card Logging**: Data persistence.
